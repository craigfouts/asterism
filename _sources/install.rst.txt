Clone
-----

.. tab-set-code::

    .. code-block:: MacOS

        git clone https://github.com/craigfouts/asterism.git
        cd asterism
        python -m venv .env
        source .env/bin/activate
        pip install -r requirements.txt

    .. code-block:: Windows

        git clone https://github.com/craigfouts/asterism.git
        cd asterism
        python -m venv .env
        .env\Scripts\activate
        pip install -r requirements.txt
